# Sistema de Gestión de Equipos Mineros

## Descripción
Aplicación web para gestionar equipos mineros, controlar sus horómetros y registrar sus mantenimientos.

## Tecnologías
- Backend: Laravel 11 y PHP.
- Frontend: Vue 3 y Vite.
- Base de datos: MySQL.
- Contenedores: Docker.
- Control de versiones: Git y GitHub.

## Funcionalidades
- Registro y consulta de equipos.
- Clasificación por tipo de equipo.
- Control de horómetro.
- Cálculo de horas restantes para mantenimiento.
- Identificación de equipos que requieren mantenimiento.
- Registro e historial de mantenimientos.

## Estructura
- `back/`: API REST desarrollada en Laravel.
- `vue/`: aplicación frontend desarrollada en Vue.

## Configuración
Cada módulo cuenta con su archivo `.env.example` para orientar la configuración de variables de entorno.

## Despliegue
Se está trabajando en la publicación del backend y frontend mediante Render.
